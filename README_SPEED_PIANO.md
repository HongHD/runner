## 💡 기술 하이라이트

### 1. 실시간 점수 계산
```javascript
const calculateScore = (isCorrect, elapsedTime) => {
    if (!isCorrect) return 0;
    let accuracyScore = 100;
    let speedBonus = Math.max(0, 50 - (elapsedTime / 100));
    return Math.round(accuracyScore + speedBonus);
}
```

### 2. 무작위 음 생성 알고리즘
```javascript
const generateNotesForLevel = (level) => {
    const count = Math.min(level + 2, 10);
    const allNotes = ['C', 'D', 'E', 'F', 'G', 'A', 'B', 'C_HIGH'];
    const selected = [];
    for (let i = 0; i < count; i++) {
        selected.push(allNotes[Math.floor(Math.random() * allNotes.length)]);
    }
    return selected;
}
```

### 3. 실시간 동기화
- 플레이어 입력 → 즉시 서버 전송 → 관리자에게 브로드캐스트
- 지연 시간: <100ms
- 동시성 처리: processedPids로 중복 방지
